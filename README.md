# 节点

本仓库用于展示 Easytier 公共节点的地址，https 地址由 cloudflare 托管

节点地址：

```
https://etnode.zkitefly.eu.org/node1
https://etnode.zkitefly.eu.org/node2
```

node1 为在雨云的重庆云服务器节点1（服务器禁非中国大陆访问）

node2 为 cloudflare woeker 搭建的节点（使用 [IceSoulHanxi/easytier-ws-relay](https://github.com/IceSoulHanxi/easytier-ws-relay) 搭建）

http1 限制仅中国大陆返回真实内容，http2 限制非中国大陆返回真实内容。

两节点均禁中转
